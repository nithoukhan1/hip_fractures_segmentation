# Experiment register

Every Kaggle run gets one line in the table at the **bottom** of this file. `scripts/register_run.py` appends the line automatically when a run is filed from `results/_inbox/`.
- **Track:** Shared (S runs), Paper A (A runs, SLG-Net), Paper B (R runs, RefFrac).
- **Metrics** are out-of-fold or validation, unless the run is a frozen *final* run or a fixed baseline (then test-set results are included).
- **Analyses** that combine runs (intervals, paired tests, per-class breakdowns) are in `results/analysis/<name>/`:
  - C01 = S01 vs S02, C02 = S01 vs S03, C03 = the classifiers S04–S06 vs S01, C04 = the segmenters S07–S10 vs S01, C05 = S06 vs S10;
  - M1_baseline_table = all ten baselines S01–S10 side by side (milestone M1);
  - C06 = Paper A's fold-0 development runs vs M0;
  - C10 = review of Paper B's orientation rule (`scripts/check_orientation.py`, no run).
  - Planned: C11 (Paper A's second-seed check, `Analysis/06_Step3_PaperA_Protocol.md` §10) and C07–C09 (Paper A's final runs; §7).
  - Planned for Paper B (`Analysis/08_Step5_PaperB_RefFrac_Protocol.md` §4–§5): C12 (fold-0 development of R4 vs M0), C13 (RQ-B1: M0, R2, R3, R4), C14 (R7: RQ-B2 and RQ-B3), C15 (RQ-B4: R4 vs R1, R5, R6a, R6b) and C16 (Paper B's main table).
- Details of each run are in `results/<RUN>/NOTES.md`.
