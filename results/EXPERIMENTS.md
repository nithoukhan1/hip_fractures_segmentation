# Experiment register

Every Kaggle run gets one line in the table at the **bottom** of this file. `scripts/register_run.py` appends the line automatically when a run is filed from `results/_inbox/`.
- **Track:** Shared (S runs), Paper A (A runs, SLG-Net), Paper B (R runs, RefFrac).
- **Metrics** are out-of-fold or validation, unless the run is a frozen *final* run or a fixed baseline (then test-set results are included).
- **Analyses** that combine runs (intervals, paired tests, per-class breakdowns) are in `results/analysis/<name>/`:
  - YOLO resolution analysis = YOLOv8s-seg vs YOLOv8s-seg at 640 px, the YOLO version analysis = YOLOv8s-seg vs YOLO11s-seg, the classifier analysis = the three classifiers vs YOLOv8s-seg, the segmenter analysis = the segmenters the segmentation baselines vs YOLOv8s-seg, the mask-task analysis = ConvNeXt-T classifier vs ConvNeXt U-Net;
  - M1_baseline_table = all ten baselines side by side (the baseline-table milestone);
  - SLG-Net development analysis = Paper A's fold-0 development runs vs ConvNeXt U-Net;
  - Orientation review = review of Paper B's orientation rule (`scripts/check_orientation.py`, no run).
  - SLG-Net second-seed check = Paper A's second-seed check; the RefFrac development analysis = Paper B's fold-0 development runs vs ConvNeXt U-Net.
  - SLG-Net ablation analysis = Paper A's ablation chain (SLG-Net ablation chain); the SLG-Net interpretability analysis = Paper A's interpretability tests (oracle, region deletion, risk–coverage, geometry; section 2b SLG-Net vs ConvNeXt U-Net under deletion with `A1_m0_deletion`); the SLG-Net main-table analysis = Paper A's main table (SLG-Net against every baseline).
  - Reference analysis = Paper B's reference question (reference question: ConvNeXt U-Net, the random-reference model, the nearest-reference model, RefFrac, plus the reference tests of every R run); the own-hip analysis = own-hip model, the own other hip and the pairing shortcut (own-hip question, the pairing-shortcut question); the RefFrac component analysis = alignment, fusion and AASN (alignment-and-fusion question: RefFrac vs the AASN-style model, the concatenation model, the no-alignment model, the affine-alignment model); the RefFrac main-table analysis = Paper B's main table (RefFrac against every baseline). Garden I-II tests, subgroups and the own-hip model's modes: `scripts/run_refstats.py`.
  - Ensemble analysis = ensembles of saved predictions (ConvNeXt U-Net, a second ConvNeXt U-Net, SLG-Net, RefFrac; exploratory, no GPU): `scripts/run_ensemble.py`.
- Details of each run are in `results/<RUN>/NOTES.md`.
